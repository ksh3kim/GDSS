When I provide a numbered list of code modification requests, do not execute all items automatically.

Treat each numbered item as an independent task option. First, present or recognize the numbered list, then wait for me to specify which number I want to execute. When I enter a number, perform only the task associated with that exact number.

Do not perform any other numbered items unless I explicitly select them. Do not batch, merge, infer, or preemptively apply multiple changes. If I enter multiple numbers, only then perform those selected items. If my input is unclear, ask me which number I want to execute before making any changes.

The numbering format may vary. Always follow the rule: numbered code-change requests require explicit number selection before execution.
